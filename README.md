![Screenshot 2025-05-01 103611](https://github.com/user-attachments/assets/af5def97-a117-434f-9c25-6c1526b5bcd5)# Online Medicine Store

An online platform for browsing, purchasing, and managing medicines. Built using Java Servlets, JSP, and MySQL, this project simulates a complete e-commerce system tailored for pharmaceutical products.

---

## 🧾 Overview

The Online Medicine Store allows users to:
- Browse available medicines
- Add products to a cart
- Place and manage orders
- Genearting Bills
- Perform admin operations like adding new medicines and managing stock

---

## ✨ Features

- User registration and login
- Admin dashboard for product management
- Order placement and order history
- Secure authentication
- Responsive UI (HTML/CSS)
- Database-driven design with MySQL

---

🛠️ Technologies Used
 1. Java (JSP, Servlets)
 2. Apache Tomcat
 3. MySQL
 4. HTML/CSS
 5. AJAX (Asynchronous JavaScript)
 6. JDBC
 7. Git/GitHub
